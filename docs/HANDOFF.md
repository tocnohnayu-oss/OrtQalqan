# Текущее состояние

Обновлено 23.10.2026. Этот файл обновляется после каждого значимого этапа.

## Контекст

OrtQalqan — конкурсный веб-прототип для инспекторов ЧС. Защита 06.11.2026. Устройства — телефон и компьютер, языки — RU/KK, интерфейс — минималистичный с приоритетом схемы здания. Демо — НИШ ЕМН Петропавловска, с синтетическими помещениями и площадями.

## Подготовлено

- Продуктовый сценарий и словарь необходимых входных данных.
- Компоновка рабочего места и правила графического представления.
- Обзор публичных материалов Inspect Point и SafetyCulture/Mitti.
- Реестр нормативных источников и незавершённых проверок.
- Технические границы модулей и критерии демонстрации.
- Журнал подтверждённых требований и проектных допущений.

## Текущий этап

После подготовки написан React/TypeScript-прототип: схема, редактор зон/этажей, RU/KK, локальный черновик, резервный JSON, загрузка изображения плана с метками, предварительный расчёт и экспорт PDF. Начальный сценарий — синтетические 3 этажа и 9 зон школы. Результат помечен предварительным; нормативные ограничения сохранены в ядре и отчёте.

Восемь существенных проверок расчётного ядра прошли локально через `npm test`. Установка UI-зависимостей локально не завершилась: DNS недоступен для npm registry. Проверка выполнена в GitHub Actions: **успешно** прошли установка, TypeScript/Vite-сборка, проверки ядра и браузерный сценарий.

Доказательство: [run 39940598222](https://github.com/tocnohnayu-oss/OrtQalqan/actions/runs/39940598222), исходный коммит `81611ade175ff1da91cd6e0446c8af6d5a5e255a`. [Артефакт](https://github.com/tocnohnayu-oss/OrtQalqan/actions/runs/39940598222/artifacts/12496071631) содержит `dist`, сгенерированный `package-lock.json`, скриншоты и PDF RU/KK. Визуальный просмотр скриншотов человеком и экспертная проверка нормативов ещё не выполнены. Проверка PDF пока подтверждает скачивание и сигнатуру файла; извлечение текста для контроля всех казахских символов — отдельная задача.

Сценарий `scripts/smoke.mjs` проверяет перерасчёт площади, загрузку плана/метку, PDF RU/KK, мобильную ширину, локальное восстановление и ошибки браузера. Артефакты — сборка, lock-файл, скриншоты и образцы PDF. История расчётов первой версии хранится в текущей сессии, черновик — в localStorage. Импорт допускает нулевую площадь как незаполненный черновик; ядро блокирует расчёт такой зоны.

## Для следующего разработчика

Прочитать `AGENTS.md`, `DECISIONS.md` и документ своей области. Нормативный набор требует отдельного внимания: стандарт отсылает к историческим Правилам; в актуальном приложении 3 найдены таблицы, но соответствие паспортным моделям и сочетание правил ещё требуют верификации.

Ближайшие задачи: посмотреть интерфейс вместе с пользователем/инспектором, проверить PDF глазами и извлечением текста, сохранить сгенерированный lock-файл из CI в репозиторий, подтвердить предварительную формулу и типоразмер ОУ. Для реальной школы заменить синтетические данные измеренными. Публикацию продолжить после восстановления Git-сети; не создавать второй Site.

При параллельной работе назначать непересекающиеся области файлов и договориться о контракте данных. Удобные границы: расчётное ядро/источники, визуальное рабочее место, локализация/PDF. Названия этих областей не означают, что агенты уже запущены.
