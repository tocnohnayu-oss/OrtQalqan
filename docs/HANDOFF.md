# Текущее состояние OrtQalqan

Обновлено 23.10.2026. Входная точка для тиммейта и следующего агента: `AGENTS.md`, затем этот файл и документ своей области.

## Требования и визуальное направление

Пользователь — инспектор ЧС. Телефон и компьютер, полноценные RU/KK. Пользователь отверг однообразный первый интерфейс и потребовал профессиональный узнаваемый бренд, обязательную светлую тему, детальный план, разные иллюстрации и самостоятельное визуальное ревью с разбором неудобств.

Направление — полевой атлас: тёплая бумага, графит, терракота, монограмма Q. См. `BRAND.md`. Демо — НИШ ЕМН Петропавловска. Подтверждены название и адрес; помещения, планировка, площади, условия и оборудование синтетические.

## Что работает

- Детальный условный план со стенами, дверями, окнами, коридором, лестницей, входом и обстановкой помещений. Выбор зоны мышью и клавиатурой, масштаб 50–200 %.
- Стены сохраняют положение при изменении расчётной площади. Для неизвестного назначения не выдумывается мебель.
- Загрузка своего изображения плана и метки ОП/ОУ с нормализованными координатами.
- Контекстные параметры; на телефоне — нижний native dialog с фокусом и постоянными кнопками. Расчёт и PDF доступны из мобильной панели.
- Оригинальные SVG: знак, учебный корпус, оборудование и восемь разных рабочих сцен. Сцены — оформление, не классификатор пожарной опасности.
- Шесть сравнений «сейчас → при изменении»: площадь, чувствительная электроника, неизвестные материалы, холодные условия, АУПТ, оборудование на ТО.
- Симуляция не меняет оригинал. Отдельная кнопка применяет изменение к черновику. Сравнение показывает выбранную зону; минимум этажа считается в полном результате.
- Замечания инспектора `Zone.notes` до 3000 символов: локальный черновик, JSON, снимок и PDF. Старый формат без поля допустим.
- Предварительный расчёт, источники, уточнения, устаревание после редактирования, история текущей сессии, резервный JSON.
- PDF RU/KK из конкретного снимка, включая схему, параметры, замечания, источники, статус демонстрации и сведения о непроверенном размещении.

## Граница нормативной готовности

Существующий профиль `public-pilot-2026-10-23` предварительный и ограничен общественными помещениями A/E. Интерпретация пропорционального расчёта с округлением, связь исторической ссылки стандарта с актуальными Правилами и типоразмер ОУ требуют экспертной верификации. Подробности — `NORMATIVE_RESEARCH.md`.

Для A/E с чувствительным оборудованием, специальных веществ и неподдержанных категорий ядро требует подбор. Автоматическое пожаротушение не снижает комплект автоматически. Проверка количества не подтверждает расстояния и полную безопасность объекта. Геометрия условной схемы не является фактическим планом школы.

## Проверки и визуальное ревью

Локально прошли TypeScript/Vite-сборка и **15 существенных проверок** ядра/сценариев через `npm test`. Браузерный сценарий также проверяет выбор с клавиатуры, масштаб, светлую тему при системной тёмной, стабильность стен, сравнение без изменения черновика, применение, заметки, разметку, PDF RU/KK, восстановление и ширины 390/320 px.

Финальная комплексная проверка: [run 39946301992](https://github.com/tocnohnayu-oss/OrtQalqan/actions/runs/39946301992), функциональный коммит `106c7f9a6569ddbce37bb9e74794f027a4f0ebea`. Успешны сборка, 15 проверок ядра/сценариев, браузерный сценарий и публикация материалов ревью. Точный `sourceSha` также записан в `design-review/review/checks.json`.

Скриншоты получены через GitHub, сохранены локально и визуально рассмотрены агентом. По первому просмотру исправлены длинная мобильная форма, возврат к плану, перестройка стен и уведомление на старом языке. По следующему — масштаб touch-кнопок, отдельное действие расчёта, выделение без опоры только на цвет, шрифт мобильных полей и нейтральная подложка диалогов.

Автоматические скриншоты и примеры PDF синтетического демо хранятся в ветке `design-review`, папке `review`. Исходники — в `main`. CI получает `contents: write` для обновления этой отдельной ветки; пользовательские локальные черновики в CI не отправляются. Код этого шага — `scripts/publish-review.sh`. Токен GitHub Actions не записывается в файлы.

Ревью реальным инспектором и экспертная проверка нормативов ещё не проведены. Демонстрационные PDF RU/KK получены из GitHub и проверены локально `pdftotext`: читаются заголовки, замечание инспектора и все буквы Ә Ғ Қ Ң Ө Ұ Ү Һ І. Первый лист PDF также отрисован для визуального просмотра. В отчётах сохранены пометки предварительного профиля и синтетических данных.
