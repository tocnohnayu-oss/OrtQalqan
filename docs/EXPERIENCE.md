# Дизайн и пользовательский опыт

## Направление

Спокойное инженерное рабочее место. Светлый фон, чёткая типографика, тонкие границы, один акцентный цвет. В центре — объект и его зоны. Декоративные диаграммы, круговые проценты «безопасности», тяжёлые тени и сетка однотипных карточек не помогают основной задаче.

## Компоновка компьютера

```text
┌──────────────────────────────────────────────────────────────┐
│ OrtQalqan    Объекты / НИШ ЕМН       Сохранено    RU / ҚАЗ    │
├──────────────┬─────────────────────────────┬─────────────────┤
│ Этажи        │ Схема / План                │ Выбранная зона  │
│ 03           │                             │ Название        │
│ 02           │     Зоны этажа              │ Площадь         │
│ 01           │     Статусы и ОП/ОУ         │ Условия         │
│ + этаж       │                             │ Обоснование     │
├──────────────┴─────────────────────────────┴─────────────────┤
│ Комплект по объекту            Результат / Сформировать PDF  │
└──────────────────────────────────────────────────────────────┘
```

На средних экранах список этажей превращается в горизонтальный переключатель. На телефоне одна рабочая область, компактная верхняя строка, параметры в выдвижном листе и закреплённое основное действие. Перетаскивание имеет альтернативу обычными кнопками.

## Визуальная система

| Элемент | Решение |
| --- | --- |
| Фон | Холодный почти белый; рабочая схема на едва заметной точечной сетке |
| Текст | Тёмный графит, спокойный серый для второстепенных подписей |
| Акцент | Глубокий бирюзовый для действий и выбранной зоны |
| ОП / ОУ | Различимые обозначения, иконка + короткий текст; цвет служит дополнительным признаком |
| Ошибка / уточнение | Красный / янтарный, обязательная текстовая причина |
| Шрифт | Noto Sans с полноценными казахскими символами, локальные файлы |
| Размеры | Основной текст 14–16 px; крупные числовые итоги; умеренные заголовки |
| Формы | Подпись над полем, единица измерения внутри/рядом; ошибки у своего поля |
| Иконки | Один набор Lucide; подписи для основных действий |
| Движение | Короткие переходы; учитывать reduced motion |

Не полагаться на hover, цвет, мелкий tooltip или иконку без доступного имени. Небольшая поясняющая фраза полезнее непонятного символа.

## Что показывает графика

Схема показывает реальные сущности данных: этажи, помещения, выбранную зону, класс/условия, необходимый комплект. Нажатие на помещение открывает его параметры и основание результата. Итог по этажу виден без открытия каждой зоны.

Условные блоки не изображают подтверждённую архитектуру школы. На неподтверждённой схеме нельзя рисовать окружности «зоны покрытия», вычислять расстояния по пикселям или обещать оптимальное размещение.

В режиме плана изображение пользователя остаётся подложкой. Метка огнетушителя выбирается нажатием, получает тип, связанный этаж и зону; её можно убрать. До появления масштаба, препятствий и проверенного алгоритма измерений размещение остаётся непроверенным.

## Результаты и детали

Верхний уровень отвечает на три вопроса: какой комплект нужен, в каких зонах есть вопросы, можно ли выгрузить актуальный результат. Подробности формулы и источника раскрываются по действию «Почему столько?».

Сравнение имеющегося оборудования с требуемым — горизонтальные полосы или простая пара чисел. Статистика по времени, произвольные индексы риска и графики без исходных данных не нужны.

## Языки и доступность

Единый переключатель RU / ҚАЗ работает без потери ввода. Обе версии включают состояния формы, подписи SVG, единицы, сообщения сохранения, справку и PDF. Машинный перевод нормативных терминов требует проверки человеком, владеющим казахским.

Для основных touch-действий целевой размер — 44 px и более. Это продуктовый ориентир; минимум WCAG 2.2 AA для соответствующего критерия имеет исключения и не равен универсальному требованию 44 px. Источник: [W3C, Target Size Minimum](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html).

Текстовые альтернативы схемы, клавиатурный выбор зон, контраст, видимый фокус и корректные заголовки обязательны. [Radix](https://www.radix-ui.com/primitives/docs/overview/accessibility) помогает с фокусом и клавиатурными шаблонами, но доступность приложения проверяется целиком.
