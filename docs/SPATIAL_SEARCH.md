# Поиск и расположение помещения · 28.10.2026

После просьбы «ещё лучше сделай» выбран конкретный разрыв рабочего сценария: поиск по зданию находил помещение/оборудование, но открывал только исходную форму. Прямой переход к той же комнате в модели был доступен из листа внимания, но не из поиска.

## Решение до реализации

- В каждой строке два самостоятельных действия: открыть исходную запись и показать расположение помещения. Основное действие сохраняет точный Asset.id. Вторая кнопка относится к комнате, не к вымышленной позиции огнетушителя.
- Настоящий контур открывается в 3D при вызове из здания; из рабочего плана остаётся 2D. Зона только с меткой изображения возвращается к этому изображению, включая смешанный этаж с контурами других комнат. У зоны без контура/метки нет фиктивного перехода.
- Поиск ограничен текущим Building, данные/запрос не сохраняются отдельно. Навигация не меняет Building, расчёт, отметки осмотра или дату. Слой модели при поиске сохраняется; лист внимания по-прежнему явно открывает слой осмотра.
- Для двух действий используются обычные кнопки, без вложенных кнопок внутри listbox option. Поле поиска остаётся нативным searchbox; Tab/Enter работают с настоящими действиями. Стрелки переводят фокус между строками, Escape закрывает native dialog и возвращает прежний фокус.
- На телефоне оба действия имеют цели от 44 px и текстовую подпись. Название комнаты/этажа переносится полностью. Неизвестная геометрия не называется нарушением и не скрывает исходную запись.

## Проверить

Одинаковые номера оборудования на разных этажах; точный переход к комнате и Asset.id; повторный запрос того же контура; изображение на смешанном этаже; неизвестная привязка; сохранение слоя/ракурса и освобождение GPU при обычном выходе. Проверить 320 px KK, клавиатуру, полные имена, отмену поиска и неизменность локального черновика. Итоговые SHA/CI/снимки записать после фактической проверки.

Первичные ориентиры доступности: [WAI: Button pattern](https://www.w3.org/WAI/ARIA/apg/patterns/button/) и [WAI: Modal dialog pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/). Семантика применяется к нашей реализации; внешней сертификации доступности нет.
