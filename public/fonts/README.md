# Roboto Condensed

Copyright 2011 The Roboto Project Authors. SIL Open Font License 1.1, see `OFL-RobotoCondensed.txt`.

Unmodified variable upright TTF from [Google Fonts upstream](https://github.com/google/fonts/tree/main/ofl/robotocondensed), downloaded 24 October 2026. Weight axis 100–900. Used locally for display headings and numbered indices; Noto remains the body and PDF font. FontTools cmap verification covers every Kazakh-specific uppercase/lowercase letter Ә Ғ Қ Ң Ө Ұ Ү Һ І. No third-party font requests.
